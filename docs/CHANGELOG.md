# 变更日志

## 2026-08-23 - 实时审查与规则激活架构深化

- 实时审查支持复用已完成的本地规则结果，接入豆包语义复核时不再重复执行本地规则。
- 新增 `RuleActivationIndex`，按直播间、商品、平台和行业编译统一的词级/语义规则快照，运行时不再直接拼接两套规则来源。
- 纠错、说话人修改和备注修改的 `review.edited` 事件携带完整修改后内容；重启重建优先重放事件，旧版本事件保留兼容回放。
- 新增 `SessionEventKernel`，实时投影与重启重建共享纯事件 reducer；规范化转录投影与快照投影分离。
- 新增 `FindingReviewModule` 和 `ManualDeliveryModule`，违规处置、规则确认、语义单元确认和人工同步任务不再由 HTTP 路由直接操作 SQLite。
- 增加本地规则单次执行、规则层级排序和事件重建的回归测试。
- 不改变 HTTP/WS 外部接口和 SQLite 表结构；无需数据迁移。回滚目标为本次变更前的提交或标签。
- 验证：`npm test`（209 项）、`npm run build`、`npm run test:e2e`（桌面/移动端）、`git diff --check`。

## 2026-08-14 - 治理闭环修复

- 旧版本资源同步任务迁移后统一回到待人工确认，后台交付只处理已批准任务。
- 普通账号查询同步任务时按直播间权限过滤，运营审核账号才可查看全库。
- 语义规则增加商家提交、运营采纳/待定/舍弃和公共规则包复制链路。
- 规则包创建补充平台、行业、直播间和商品作用域约束，避免无范围规则误变成全局规则。
- 资料管理增加商家数据库/私有知识库目标选择、人工同步按钮和失败状态显示；支持抖音与拼多多平台画像。
- 对迁移后的同一版本任务，重复点击人工同步会记录新的确认人和时间并重新排队，不会被幂等键卡在待确认状态。

## 2026-08-14 - 本地规则与话术治理基础

- 增加规则包、规则单元、规则文档版本和版本差异模型。
- 增加官方文档上传与 URL 抓取，抓取结果必须进入人工审核队列。
- 增加句级/上下文语义规则包，保留完整原话和上下文指令，不转换成单一关键词。
- 严格模式下已审核语义规则会注入豆包复核提示词。
- 规则与话术保存不再自动创建远程上传任务。
- 增加按数据库/私有知识库选择目标的人工同步接口、幂等键和版本 superseded 处理。
- 运营审核页增加文档更新和待审核语义规则入口。
- 增加规则治理模块、文档差异、语义规则和人工同步测试。
